# DARNA — دارنا

شبكة اجتماعية عقارية للجزائر، تجمع خلاصة الشبكات الاجتماعية مع اكتشاف العقارات.

## النسخة الحالية
- واجهة عربية RTL متجاوبة للهاتف والحاسوب.
- موجز عقاري مع منشورات وصور وتفاعلات وإشارات حفظ.
- بحث وفلاتر للبيع والكراء والولاية ونوع العقار.
- نشر إعلان تجريبي من الواجهة.
- صفحات تنقل: الرئيسية، اكتشف، المحفوظات، الرسائل، الملف الشخصي.
- بيانات تجريبية محلية محفوظة في متصفح الجهاز عبر localStorage.
- خادم Node بسيط لتقديم ملفات الواجهة ونقطة صحة `/health`.

## التشغيل
```bash
npm install
npm start
```
ثم افتح `http://localhost:10000`.

## النشر على Render
أنشئ Web Service من هذا المستودع، Runtime: Node، Build Command: `npm install`، Start Command: `npm start`.

## تنبيه
هذه نسخة MVP للواجهة والتجربة. الحسابات الحقيقية، رفع الصور، قاعدة البيانات، المراسلة الفورية، التحقق من الوسطاء، والإشعارات تحتاج ربط خدمات خلفية وقاعدة بيانات قبل إطلاقها للعامة. لا تستخدم بيانات شخصية حقيقية في النسخة التجريبية.
