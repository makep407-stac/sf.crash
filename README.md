# DARNA — دارنا

شبكة اجتماعية عقارية للجزائر، تجمع خلاصة الشبكات الاجتماعية مع اكتشاف العقارات.

## النسخة الحالية
- واجهة عربية RTL متجاوبة للهاتف والحاسوب.
- موجز عقاري مع منشورات وصور وتفاعلات وإشارات حفظ.
- بحث وفلاتر للبيع والكراء والولاية ونوع العقار.
- نشر إعلان تجريبي من الواجهة.
- صفحات تنقل: الرئيسية، اكتشف، المحفوظات، الرسائل، الملف الشخصي.
- بيانات تجريبية محلية محفوظة في متصفح الجهاز عبر localStorage.
- خادم Node بسيط لتقديم ملفات الواجهة ونقطة صحة `/health`.

## التشغيل
```bash
npm install
npm start
```
ثم افتح `http://localhost:10000`.

## النشر على Render
أنشئ Web Service من هذا المستودع، Runtime: Node، Build Command: `npm install`، Start Command: `npm start`.

## تنبيه
هذه نسخة MVP للواجهة والتجربة. الحسابات الحقيقية، رفع الصور، قاعدة البيانات، المراسلة الفورية، التحقق من الوسطاء، والإشعارات تحتاج ربط خدمات خلفية وقاعدة بيانات قبل إطلاقها للعامة. لا تستخدم بيانات شخصية حقيقية في النسخة التجريبية.

## إعداد المصادقة وقاعدة البيانات الحقيقية

ملفات Supabase جاهزة كبداية:
- `supabase/schema.sql`: ملفات المستخدمين والإعلانات والإعجابات والمحفوظات والتعليقات والرسائل مع سياسات RLS.
- `supabase-config.js`: ضع فيه Project URL و anon/public key فقط. لا تضع service_role key أبداً في الواجهة.

خطوات التفعيل:
1. أنشئ مشروع Supabase واربطه بهذا التطبيق.
2. نفّذ `supabase/schema.sql` في SQL Editor.
3. انسخ Project URL و anon/public key إلى `supabase-config.js`.
4. فعّل Email confirmations واضبط SMTP خاصاً للإرسال الفعلي للمستخدمين.
5. لتسجيل الهاتف، فعّل Phone Auth واضبط مزود SMS يدعم إرسال الرسائل إلى الجزائر (+213).
6. اضبط Site URL و Redirect URLs على نطاق DARNA المنشور.

واجهة التسجيل تستخدم Supabase Auth: إنشاء حساب بالبريد مع تأكيده، أو OTP للهاتف عند تهيئة مزود SMS. لا يمكن إرسال رسائل تحقق حقيقية قبل إكمال إعدادات مزودي البريد والرسائل وربط مشروع Supabase.
