# sf.crash

واجهة عربية داكنة قابلة للتثبيت كتطبيق ويب (PWA).

## الموجود حالياً
- شاشة إقلاع مدتها خمس ثوانٍ.
- شاشة دخول محلية تجريبية بكلمة المرور المطلوبة في النموذج.
- واجهة سوداء مع طائرة زرقاء وفقاعة متحركة وتأثير جزيئات.
- قائمة جانبية: حالة ربط الجلسة، سجل الجولات، ومقارنة التوقعات بالنتائج.
- إدخال يدوي للتوقع والنتيجة الفعلية مع حساب نسبة التطابق محلياً على الجهاز.

## حدود مهمة
- كلمة مرور الواجهة التجريبية `sf.2027` موجودة في JavaScript للعرض فقط؛ يمكن استخراجها، لذلك ليست حماية حقيقية.
- معرّف 1xBet لا يثبت ملكية الحساب ولا ينشئ اتصالاً به.
- ربط الحساب أو رموز الجلسة غير مفعّل. لا تضع كلمات مرور 1xBet أو Cookies أو Session Tokens في الواجهة أو المستودع.
- يلزم تكامل رسمي موثّق وخادم خلفي آمن قبل تفعيل المصادقة أو جلب الجولات.
- لا يصدر التطبيق تنبؤات حقيقية ولا يدّعي دقة أو أرباحاً. إحصاءات السجل محسوبة من البيانات التي يدخلها المستخدم يدوياً.

## التشغيل
انشر محتويات المستودع كـ Static Site مع جعل مجلد الجذر هو Publish Directory، ثم افتح رابط الموقع من الهاتف واختر Add to Home Screen / إضافة إلى الشاشة الرئيسية.
