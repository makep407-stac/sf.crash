# AQar DZ — عقار DZ

منصة اجتماعية عقارية جزائرية لاكتشاف العقارات ونشر إعلانات البيع والكراء والتواصل بين الباحثين والمعلنين.

## ما يعمل في النسخة الحالية
- واجهة عربية RTL متجاوبة للهاتف والحاسوب بهوية AQar DZ.
- موجز عقاري، بحث وفلاتر حسب البيع/الكراء ونوع العقار والولاية والدائرة والبلدية والسعر.
- قائمة إدارية جزائرية تضم 69 ولاية و587 دائرة و1541 بلدية.
- تسجيل بالبريد الإلكتروني وكلمة المرور عبر Supabase Auth، مع تأكيد البريد حسب إعدادات المشروع.
- مسار OTP للهاتف جاهز برمجياً، لكنه يحتاج مزود SMS مدفوعاً/مهيأً يدعم +213.
- نشر الإعلانات وتحميلها من قاعدة بيانات Supabase.
- تفاعلات الإعجاب والحفظ والتعليقات والرسائل الخاصة مرتبطة بقاعدة البيانات، مع سياسات وصول لكل مستخدم.
- تخزين صور الإعلانات في bucket باسم `listing-images` مع سياسات وصول.

## التشغيل المحلي
```bash
npm install
npm start
```
ثم افتح `http://localhost:10000`.

## Supabase
- Project: `AQar-DZ`
- Project URL: `https://wfrsxfpxqhhkjqrbydns.supabase.co`
- إعداد الواجهة في `supabase-config.js` يستخدم publishable key فقط.
- لا تضع أبداً `service_role` أو secret key أو كلمة مرور قاعدة البيانات في ملفات الواجهة.
- بنية قاعدة البيانات محفوظة في `supabase/schema.sql`، وقد طُبقت على المشروع المتصل.

### إعدادات مطلوبة قبل إطلاق التسجيل العام
1. ضبط Site URL و Redirect URLs في Authentication.
2. إعداد SMTP موثوق لإرسال رسائل تأكيد البريد إلى المستخدمين.
3. إعداد مزود SMS يدعم الجزائر (+213) إذا أردت تسجيل الهاتف.
4. اختبار التسجيل وتأكيد البريد من عنوان الموقع المنشور.
